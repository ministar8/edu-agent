# Knowledge 规范包

| 目录 | 内容 |
|---|---|
| `schema/` | KP / Basic 文档 / Chunk 的 JSON Schema |
| `rules/` | Basic 写作、切分、元数据、门禁规则 |
| `knowledge_points/` | KP 数据与 `schema.md` |
| `basic/` | L1 概念知识 |

## 核心分工

```text
Basic     →  是什么 / 为什么 / 怎么工作
Advanced  →  怎么做题
Exams     →  真题 / 答案 / 题目语境
KP        →  统一知识锚点
Section   →  语义关系主体
Chunk     →  检索载体
teaches   →  Basic Section → KP
```
