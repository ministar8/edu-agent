## 网络体系结构

> section_id: basic-cn-arch-model
> kp_ids: [cn.arch.model]
> primary_kp: cn.arch.model

**定义**：把通信任务划分为层次，每层向上提供服务、向下使用服务；对等层有协议。

**为什么**：通信问题复杂（物理传、成帧、路由、应用语义）；分层降低耦合、便于实现替换。

**思想**：

- **封装**：上层数据作为下层载荷，加首部
- **协议**：对等实体的约定（语法、语义、时序）
- **接口**：相邻层之间的服务访问点

常见模型：OSI 七层与 TCP/IP 四层——层次划分不同，分层原则一致。

## 网络性能指标

> section_id: basic-cn-arch-performance
> kp_ids: [cn.arch.performance]
> primary_kp: cn.arch.performance

**口径**：

- 时延：发送、传播、处理、排队
- 带宽：链路最高数据率
- 吞吐：实际通过量
- 往返时间 RTT

**思想**：性能是多段时延之和；「带宽高」不等于「RTT 短」。

## 网络的组成与分类

> section_id: basic-cn-arch-network-basics
> kp_ids: []

**定义**：

- **网络**：由若干结点（Node）和连接这些结点的链路（Link）组成。
- **互连网（internet）**：多个网络通过路由器互连而成的更大的网络，又称「网络的网络」。
- **因特网（Internet）**：当前全球最大的、采用 TCP/IP 协议族的特定互连网。

**术语**：

- **端系统（end system）**：连接在因特网边缘、供用户直接使用的主机。
- **边缘部分**：由所有端系统组成，负责通信与资源共享。
- **核心部分**：由大量网络和路由器组成，为边缘部分提供连通性与交换。

**两种端到端通信方式**：

| 方式 | 角色 | 特点 |
|---|---|---|
| 客户-服务器（C/S） | 客户请求、服务器提供 | 服务器需长期运行，可同时服务多个客户 |
| 对等连接（P2P） | 双方对等 | 不区分请求/提供方，节点兼作服务提供者 |

**分类**：

- 按交换技术：电路交换、报文交换、分组交换
- 按使用者：公用网、专用网
- 按传输介质：有线、无线
- 按覆盖范围：广域网 WAN、城域网 MAN、局域网 LAN、个域网 PAN
- 按拓扑结构：总线型、星型、环型、网状型

**思想**：因特网是「网络的网络」；边缘提供用户功能，核心提供连通与交换功能。

## 三种交换方式

> section_id: basic-cn-arch-switching
> kp_ids: []

**定义**：

- **电路交换**：通信前建立一条专用的物理通路，通信全程独占该通路，结束后释放。
- **报文交换**：以整个报文为单位存储转发，不限制报文大小，需要较大的缓存空间。
- **分组交换**：把报文切分为较短的**分组**，每个分组加上首部（含目的地址）后独立存储转发。

**分组交换机制**：路由器先把收到的分组放入缓存，再查转发表确定输出端口，然后转发出去。

**对比**：

| 对比项 | 电路交换 | 报文交换 | 分组交换 |
|---|---|---|---|
| 建立连接 | 需要 | 不需要 | 不需要（虚电路方式需先建逻辑连接） |
| 占用通路 | 独占 | 共享 | 共享 |
| 存储转发 | 无 | 以整个报文为单位 | 以分组为单位 |
| 时延 | 最小 | 较大 | 较小 |
| 线路利用率 | 低 | 高 | 高 |

**思想**：分组交换以「按需共享 + 存储转发」换取更高的线路利用率与灵活性，是计算机网络最常用的交换方式。

## 性能指标的基础公式

> section_id: basic-cn-arch-metrics-formula
> kp_ids: [cn.arch.performance]
> primary_kp: cn.arch.performance

**基本公式**：

- 发送时延 = 数据长度(bit) / 发送速率(bit/s)
- 传播时延 = 信道长度(m) / 电磁波传播速率(m/s)
- 总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延
- 时延带宽积 = 传播时延 × 带宽（单位 bit，表示链路上正在传输的数据量）
- 信道利用率 = 有数据通过的时间 / 总时间

**要点**：高速链路只降低**发送时延**，不改变传播时延；利用率越高，时延越大：

    D = D0 / (1 - U)

其中 D0 为空闲时延、U 为利用率；当 U 趋近 1 时，时延趋于无穷。

**丢包率** = 丢失分组数 / 总发送分组数，反映网络的拥塞程度。

**思想**：带宽（最高数据率）与 RTT（往返时间）是两个独立口径，「带宽高」不蕴含「RTT 短」。

## 体系结构与协议术语

> section_id: basic-cn-arch-protocol-terms
> kp_ids: [cn.arch.model]
> primary_kp: cn.arch.model

**三种常见体系结构**：

| 模型 | 层次 |
|---|---|
| OSI 七层 | 物理层、数据链路层、网络层、运输层、会话层、表示层、应用层 |
| TCP/IP 四层 | 网络接口层、网际层、运输层、应用层 |
| 五层（教学） | 物理层、数据链路层、网络层、运输层、应用层 |

**对应关系**：TCP/IP 把 OSI 的物理层与数据链路层合并为网络接口层，并去掉会话层与表示层；网络层因核心协议是 IP（网际协议）而称为网际层。

**协议三要素**：

- **语法**：所交换信息的格式
- **语义**：收发双方要完成的操作
- **同步**：收发双方的时序关系（不是时钟频率同步）

**服务相关的数据单元**：

- **SAP（服务访问点）**：相邻两层之间交换信息的接口
- **SDU（服务数据单元）**：第 N 层服务用户要求第 N 层传送的数据单元
- **PCI（协议控制信息）**：为完成对等层通信而添加的控制信息
- **PDU（协议数据单元）**：对等层次之间传送的数据单元，PDU = SDU + PCI

**封装机制**：应用数据 → 加 TCP 首部成报文段 → 加 IP 首部成数据报 → 加帧首部/尾部成帧 → 转成比特流发送；接收方逐层解封。

**思想**：分层原则一致，只是划分粒度不同；服务是「垂直」的（下层为上层提供），协议是「水平」的（对等层之间遵循）。
