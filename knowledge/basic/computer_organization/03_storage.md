## 存储层次

> section_id: basic-co-storage-hierarchy
> kp_ids: [co.storage.hierarchy]
> primary_kp: co.storage.hierarchy

**基本思想**：寄存器→Cache→主存→外存，速度递减、容量递增、位价递减。

**为什么**：CPU 与主存速度差持续存在；用少量快存挡住大部分访存。

**机制**：依靠**局部性**（时间局部、空间局部）把常用数据搬到上层。

---

## Cache

> section_id: basic-co-storage-cache
> kp_ids: [co.storage.cache]
> primary_kp: co.storage.cache

**定义**：位于 CPU 与主存之间的小容量高速存储，对软件透明。

**为什么**：命中时访存延迟接近 Cache；目标是提高命中率。

**机制**：主存块调入 Cache 行；地址划分标记/组号/块内地址；缺失时调块并可能替换。

---

## Cache 映射方式

> section_id: basic-co-storage-cache_mapping
> kp_ids: [co.storage.cache_mapping]
> primary_kp: co.storage.cache_mapping

**定义**：主存块可放到 Cache 哪些行的规则。

**思想**：

- **全相联**：任意行，灵活、冲突少，查找代价高
- **直接映射**：固定一行，硬件简单，冲突多
- **组相联**：折中——组间直接、组内全相联

**特点**：映射越灵活，同样容量下冲突失效越少，但查找与实现越复杂。

## 替换算法与写策略

> section_id: basic-co-storage-cache_replace_write
> kp_ids: [co.storage.cache_replace, co.storage.cache_write]
> primary_kp: co.storage.cache_write

**替换**（相联时）

**思想**：缺块且组满时选一行调出（如 LRU 等）；策略影响后续命中。

**写策略**

**问题**：写 Cache 后主存如何同步。

**机制思想**：

- **写直达**：同时写主存，一致性简单、总线压力大
- **写回**：置脏位，调出时写回，带宽省、一致性复杂

## 主存储器

> section_id: basic-co-storage-main_memory
> kp_ids: [co.storage.main_memory]
> primary_kp: co.storage.main_memory

**定义**：CPU 可直接寻址的工作存储（DRAM 等）。

**机制**：按地址译码读写；容量、带宽、延迟是核心参数。

**思想**：主存是 Cache 与外存之间的「工作集」所在地。

---

## 虚拟存储器

> section_id: basic-co-storage-virtual_memory
> kp_ids: [co.storage.virtual_memory]
> primary_kp: co.storage.virtual_memory

**定义**：把「逻辑地址空间」与「物理内存」解耦，使程序看到连续大空间。

**为什么**：物理内存有限且需多道程序共享；让编译与用户不关心实页位置。

**机制思想**：

- 地址转换（页表/段表）完成虚→实
- 不在内存则缺页，由系统调入
- 与 Cache 类似：映射、查找、替换，只是尺度更大、涉及磁盘

## 存储器的分类

> section_id: basic-co-storage-classification
> kp_ids: []

**按作用（层次）分**：

- **高速缓冲存储器（Cache）**：位于 CPU 与主存之间，存取速度与 CPU 匹配，容量小、价格高。
- **主存储器（主存/内存）**：存放运行期间所需的程序和数据，CPU 可直接随机访问，容量较小、速度较快、每位价格较高。
- **辅助存储器（辅存/外存）**：主存的后援，存放暂不使用的信息，CPU 不能直接访问，容量极大、速度较慢、单位成本低。

**按存取方式分**：

| 类型 | 存取特点 | 例子 |
|---|---|---|
| 随机存储器 RAM | 存取时间与物理位置无关 | 主存、Cache |
| 顺序存取存储器 SAM | 只能按物理顺序存取 | 磁带 |
| 直接存取存储器 DAM | 先定位小区域，再在区域内顺序查找 | 机械硬盘 |
| 相联存储器 CAM | 按内容而非地址访问 | 快表 |

速度大致为 RAM > DAM > SAM。

**按信息可更改性分**：读写存储器（可读可写，如 RAM、磁盘）与只读存储器（ROM，只能读，断电不丢失）。

**按信息可保存性分**：

- **易失性存储器**：断电后信息消失，如 RAM（主存、Cache）。
- **非易失性存储器**：断电后信息仍保持，如 ROM、磁表面存储器、光存储器。

**破坏性读出 vs 非破坏性读出**：读出后原信息被破坏的称破坏性读出（如 DRAM，读出后需再生）；读出后原信息不破坏的称非破坏性读出（如 SRAM、ROM、磁盘）。

## 存储器性能指标

> section_id: basic-co-storage-performance
> kp_ids: [co.storage.main_memory]

**容量**：

    存储容量 = 存储单元个数 × 存储字长

**单位成本**：

    每位价格 = 总成本 / 总容量

**存取时间（Ta）**：从启动一次存储器操作到完成该操作所经历的时间，分读出时间与写入时间。

**存取周期（Tm）**：连续两次独立访问存储器操作之间所需的最小时间间隔。

    存取周期 = 存取时间 + 恢复时间

**数据传输率（主存带宽）**：

    数据传输率 = 数据的宽度 / 存储周期

对破坏性读出的存储器，因读出后需要再生，存取周期往往比存取时间大得多。

## SRAM 与 DRAM

> section_id: basic-co-storage-ram
> kp_ids: [co.storage.main_memory]

**定义**：二者都是半导体随机存储器、易失性存储器。**SRAM（静态 RAM）** 用双稳态触发器寄存信息；**DRAM（动态 RAM）** 用栅极电容的电荷充放电寄存信息。

**对比**：

| 特点 | SRAM | DRAM |
|---|---|---|
| 存储元 | 触发器 | 电容 |
| 破坏性读出 | 非破坏性 | 破坏性（读出后需重写/刷新） |
| 运行速度 | 快 | 慢 |
| 集成度 | 低 | 高 |
| 功耗 | 大 | 小 |
| 存储成本 | 高 | 低 |
| 地址传送 | 行列地址同时送 | 分两次送（地址复用） |
| 主要用途 | 高速缓存 Cache | 主机内存 |

**思想**：SRAM 快而贵，用作 Cache；DRAM 慢而密，用作大容量主存。

## DRAM 的刷新与地址复用

> section_id: basic-co-storage-refresh
> kp_ids: [co.storage.main_memory]

**刷新**：DRAM 电容电荷只能维持约 1~2 ms，即使不断电信息也会消失，故每隔一定时间（通常 2 ms）必须刷新。刷新实质是先读出原信息、再由刷新放大器重新写入的再生过程。

**刷新特点**：

- 刷新不依赖 CPU 控制，所有芯片同时被刷新。
- 刷新类似于读操作，但只需给栅极电容补充电荷，不需要信息输出。
- 刷新单位是**行**，只需行地址。

**三种刷新方式**：

- **集中刷新**：在一个刷新周期内用一段固定时间逐行再生，期间停止读写，此期间称死时间（访存死区）。读写不受刷新影响，但有死区不能访存。
- **分散刷新**：把每行的刷新分散到各工作周期，每个工作周期前半段正常读写、后半段刷新某一行。没有死区，但加长了存取周期。
- **异步刷新**：前两者的结合，把刷新周期除以行数得到刷新间隔，每隔该时间刷新一行。既缩短死时间，又充分利用最大刷新间隔。

**地址复用**：DRAM 的行列地址分两次传送，地址线数量减半，便于提高集成度；SRAM 一般同时送行列地址。

## 只读存储器与固态硬盘

> section_id: basic-co-storage-rom
> kp_ids: []

**ROM 特点**：非易失性，断电后数据不丢失；很多 ROM 也具有随机存取特性。

**分类**：

- **MROM（掩模式）**：内容由厂家写入，之后无法更改。
- **PROM（一次可编程）**：可一次性编程，写入后无法改变。
- **EPROM（可擦除可编程）**：可多次改写；擦除方式分紫外线擦除（UVEPROM）与电擦除（EEPROM）。
- **闪速存储器（Flash）**：不加电可长期保存信息，又能在线快速擦除和重写，位密度比 RAM 高。先擦除再写入，故写速度比读速度慢。

**固态硬盘（SSD）**：基于闪存，由控制单元（闪存翻译层）与存储单元（Flash 芯片）组成。

- 芯片内含多个**块（block）**，每块含多个**页（page）**。
- 以**页为单位读/写**，以**块为单位擦除**。
- 支持随机访问；读快、写慢——写某一页前若该页已有数据，需把块内其它页复制到新的擦除块再写入。
- 存在**磨损均衡**思想：把擦除平均分布到各块以提升寿命，分动态磨损均衡与静态磨损均衡。

**BIOS**：主板上的 ROM 芯片存储「自举装入程序」，负责引导装入操作系统。

## 多模块存储器与交叉编址

> section_id: basic-co-storage-multimodule
> kp_ids: [co.storage.main_memory]

**动机**：CPU 读写速度远快于主存，用并行技术提高访存速度。分**空间并行**（双端口 RAM）与**时间并行**（多模块存储器）。

**单体多字存储器**：只有一套读写控制电路、地址寄存器和数据寄存器，每个存储单元存 m 个字、总线宽度也为 m 个字，一次并行读出 m 个字。缺点是要求指令和数据连续存放，遇到转移指令效果不明显。

**多体并行存储器**：由多个模块组成，各模块有独立的读写控制电路、地址寄存器和数据寄存器，可并行或交叉工作。

- **高位交叉编址**（顺序方式）：高位为体号、低位为体内地址，主要用于容量扩展；访问一个连续块时先在一个模块内顺序访问，不能并行，不提高吞吐率。
- **低位交叉编址**（交叉方式）：低位为体号、高位为体内地址，主要用于提高带宽与访问速度；连续数据分布到相邻模块，用流水线方式并行存取。

**带宽公式**：设模块数 m、存储周期 T、总线传输周期 r、字长 W、连续存取 n 个字，

    带宽 = n·W / (T + (n−1)·r)

为使流水线不间断，应保证 m ≥ T/r。为避免冲突，通常取 m = T/r。

## 磁盘存储器

> section_id: basic-co-storage-disk
> kp_ids: []

**定义**：外存目前主要使用**磁表面存储器**。硬盘由磁盘驱动器、磁盘控制器和盘片组成；盘片分为若干**记录面**，每面分若干**磁道**，每条磁道分若干**扇区**，扇区是磁盘读写的最小单位。

**容量**：分**非格式化容量**（磁化单元总数，记录 bit 的上限）与**格式化容量**（按特定记录格式可存储的信息总量）。格式化容量 < 非格式化容量。

**记录密度**：

- **道密度**：沿半径方向单位长度的磁道数。
- **位密度**：磁道单位长度上能记录的二进制位数。因各磁道存储的数据量相同而内侧磁道更短，故越内侧的磁道位密度越大。
- **面密度**：位密度与道密度的乘积。

**平均存取时间**：

    平均存取时间 = 寻道时间 + 旋转延迟时间 + 传输时间

旋转延迟时间通常取磁盘转半圈的时间。

**数据传输率**：设磁盘转数为 r（转/秒）、每道容量为 N 字节，

    Dr = r · N

**RAID**：把多个物理磁盘组成一个逻辑盘，数据分割交叉存储、并行访问，兼具性能、可靠性与安全性。提高可靠性的措施为**镜像**与**奇偶校验**；RAID0 无冗余、RAID1 为镜像、更高等级采用海明码或奇偶校验等冗余方案。

## Cache 的性能与局部性

> section_id: basic-co-storage-cache_performance
> kp_ids: [co.storage.cache]

**局部性原理**：Cache 能有效工作的理论依据。

- **时间局部性**：最近用到的信息，很可能在最近的未来再次被用到（因程序中有循环）。
- **空间局部性**：最近用到的信息，其邻近的地址很可能被用到（因指令顺序存放、数据成簇存放）。

**命中率 H**：CPU 想访问的信息已在 Cache 中的比率。设访问 Cache 次数为 Nc、访问主存次数为 Nm，

    H = Nc / (Nc + Nm)     缺失率 M = 1 − H

**平均访问时间 Ta**：设命中时间 tc、未命中时间 tm，

    （同时访问 Cache 与主存）  Ta = H·tc + (1−H)·tm
    （先访问 Cache 再访问主存） Ta = H·tc + (1−H)·(tc + tm)

**系统效率 e**：

    e = tc / Ta

**思想**：用少量高速存储挡住大部分访存；命中率与访问代价共同决定平均性能。

## 多级 Cache

> section_id: basic-co-storage-multilevel_cache
> kp_ids: [co.storage.cache]

**思想**：现代计算机常采用多级 Cache（L1、L2、L3）。离 CPU 越近的级别速度越快、容量越小；越远的速度越慢、容量越大。L1 通常分为指令 Cache 与数据 Cache。

## 页式存储与快表

> section_id: basic-co-storage-paging
> kp_ids: [co.storage.virtual_memory]

**页式存储系统**：一个程序在逻辑上被分为若干大小相等的**页面**，页面大小与主存**块**大小相同，每个页面可离散地放入不同主存块。

**地址划分**：

    逻辑地址 = 逻辑页号 + 页内地址
    物理地址 = 主存块号 + 页内地址

**页表**：记录每个逻辑页面存放在哪个主存块中，用于把逻辑地址转换为物理地址。

**快表（TLB）**：一种相联存储器，可**按内容寻访**，用来存放近期访问过的页表项，加快地址变换速度。因程序的局部性，频繁访问的页表项可放入更高速的存储器。

**段页式虚拟存储器**：把程序按逻辑结构分段，每段再划分为固定大小的页；程序对主存的调入调出以页为基本单位。虚拟地址 = 段号 + 段内页号 + 页内地址，每个程序对应一个段表，每段对应一个页表。

## 存储器与 CPU 的连接

> section_id: basic-co-storage-cpu_memory_connection
> kp_ids: []

**定义**：单个存储芯片的**字长**（每个存储单元的数据位数）与**容量**（单元个数）有限，实际主存由多片芯片按需组合，与 CPU 的地址总线、数据总线和控制总线正确对接。扩展方式分**位扩展**、**字扩展**与**字位同时扩展**。

**位扩展（增加存储字长）**：当芯片的字长小于 CPU 数据线宽度时，把若干片芯片**并联**，共同组成一个更宽的存储单元。

- 各芯片的**地址线全部共用**、**片选线与读写控制线也共用**，同时被选中、同时工作。
- 数据线**分段分配**：第 i 片的数据线接到 CPU 数据总线的第 i 段，各片同一地址单元的数据拼成一个完整存储字。
- 位数需求 = 目标字长 / 单片字长，即为所需并联片数。常见情形是 1 位或 4 位芯片拼成 8 位数据宽度。

**字扩展（增加存储容量）**：当需要更多存储单元时，把若干片芯片的**单元数相加**。

- 各芯片的**数据线全部并联**到 CPU 数据总线上，读写控制线共用；同一时刻通常只有一片被选中输出数据。
- 全部芯片的数据线拼接成的宽度已满足字长，故片数取决于容量需求：所需片数 = 目标容量 / 单片容量。
- 高位地址线经**译码器**产生**片选信号**：译码器的输入端接高位地址，输出端分别接各芯片的片选端，使 CPU 访问不同地址区间时选中对应芯片。
- **地址线分配思路**：低位地址（片内地址）并联到所有芯片，用于片内单元寻址；高位地址送入译码器，用于选片。片内地址位数由单片容量决定，高位地址位数由所需芯片数决定。

**字位同时扩展**：字长与容量都不足时，先做**位扩展**得到满足字长的**位组**，再把若干这样的组按**字扩展**方式并联并加译码选片——即先横向拼宽、再纵向扩容。所需芯片总数 = 位扩展片数 × 字扩展组数。

**地址线 / 数据线 / 片选的总体分配**：

1. **数据线**：按位扩展对数分段，先确定每片负责哪几位，再决定字扩展有几组。
2. **地址线**：低 n 位为片内地址（并联到所有芯片，n 由单片容量决定），其余高位送译码器选片。
3. **片选线**：由译码器按高位地址译出，每次只使能一个（位组内）片选；位扩展的芯片共用同一片选，字扩展的不同分组用不同片选。
4. **控制线**：读/写控制线按位扩展共用；字扩展中未被选中的芯片数据线呈高阻，不干扰总线。

**思想**：用统一的总线把「窄而小的芯片」组织成「宽而大的主存」——**数据线决定位宽、地址线决定容量、片选决定哪一片说话**，三者分工明确。
