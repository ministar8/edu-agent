## 基本概念与术语

> section_id: basic-ds-intro-concepts
> kp_ids: []

**数据**：描述客观事物属性、可被计算机识别与处理的符号集合，是程序加工的原料。

**数据元素**：数据的基本单位，通常作为一个整体被处理；一个数据元素可由若干**数据项**组成。

**数据项**：构成数据元素、不可再分的最小单位（组合项可再细分，如年月日）。

**数据对象**：具有相同性质的数据元素的集合，是数据的一个子集。

**数据类型**：一个值的集合 + 定义在此集合上的一组操作。分**原子类型**（值不可再分，如 int / bool）与**结构类型**（值可再分解为分量，如结构体）。

**抽象数据类型（ADT）**：抽象数据组织及与之相关的操作。定义一个 ADT 即定义一个完整的数据结构，确定其存储结构后才能实现；它体现问题分解、抽象与信息隐藏。

**ADT 的一般定义形式**：

```c
ADT 抽象数据类型名 {
  数据对象：<数据对象的定义>
  数据关系：<数据关系的定义>
  基本操作：<基本操作的定义>
} ADT 抽象数据类型名
```

## 什么是数据结构

> section_id: basic-ds-intro-what
> kp_ids: []
> note: 导论，不为目录强行创建 KP

**基本思想**：数据结构研究数据的**逻辑组织**、**存储方式**以及其上的**基本操作**。

**为什么**：同一组数据，组织方式不同，插入、查找、遍历的代价会差一个量级。结构选择应由「问题里数据如何关联、主要做哪些操作」决定，而不是背模板。

**三要素**：

- 逻辑结构：元素之间的关系（集合、线性、树形、图状）
- 存储结构：元素在内存中的表示（顺序、链式等）
- 运算：定义在结构上的操作及其语义

## 逻辑结构与物理结构

> section_id: basic-ds-intro-logical_physical
> kp_ids: []

**基本思想**：逻辑结构描述「问题里怎么连」；物理结构描述「机器里怎么放」。二者可独立选择。

**特点**：

- 同一逻辑结构可用不同存储实现（如线性表可顺序可链式）
- 操作的代价同时受逻辑与物理结构影响
- 分析复杂度时，先分清代价来自「结构」还是「算法」

**四种存储结构对比**：

| 存储结构 | 优点 | 缺点 | 适用场景 |
|---|---|---|---|
| 顺序存储 | 随机存取，元素本身占空间最少 | 需连续空间，增删代价高 | 数组、顺序表 |
| 链式存储 | 无碎片，空间利用灵活 | 需额外指针空间，只能顺序存取 | 链表、二叉链表 |
| 索引存储 | 检索快 | 索引表占额外空间，增删需维护索引 | 数据库索引、字典 |
| 散列存储 | 查找/增删快 | 依赖散列函数，可能出现冲突 | 哈希表 |

## 算法的特性

> section_id: basic-ds-intro-algo-props
> kp_ids: []

**算法**：对特定问题求解步骤的描述，是由有限条指令构成的序列。

**五个基本特性**：

- **有穷性**：总在执行有穷步、有穷时间内结束（程序可无穷，算法不行）
- **确定性**：每条指令含义确切，相同输入得相同输出
- **可行性**：操作都能由已实现的基本运算有限次完成
- **输入**：零个或多个输入
- **输出**：一个或多个输出（必须有）

**好算法的性质**：正确性、可读性、健壮性（对非法输入能妥善处理）、高效率、低存储需求。

## 算法与复杂度

> section_id: basic-ds-intro-complexity
> kp_ids: [ds.analysis.time_complexity]
> primary_kp: ds.analysis.time_complexity

**定义**：算法是解决问题的有限、确定、可行步骤序列。

**为什么**：需要在不运行全部输入的前提下，比较算法随规模增长的开销。

**机制**：

- 时间复杂度：基本操作执行次数随规模 n 的增长量级
- 空间复杂度：辅助空间随 n 的增长量级
- 常见量级：O(1)、O(log n)、O(n)、O(n log n)、O(n²)

**思想**：

- 关注**增长率**，忽略常数与低阶项（渐进分析）
- 最坏、最好、平均是三种不同口径，比较时要对齐
- 复杂度是**上界/量级描述**，不是精确运行时间

**渐进增长**：若存在 N，使 n>N 时 f(n) 恒大于 g(n)，称 f 的增长渐进快于 g。比较算法只关注最高阶项，忽略常数与次要项。

**大 O 记法**：

- 加法规则：多项相加只保留最高阶项、系数化为 1，即 T(n)=O(f(n))+O(g(n))=O(max(f(n),g(n)))
- 乘法规则：多项相乘都保留，即 T(n)=O(f(n))×O(g(n))

**复杂度排行**：

O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) < O(nⁿ)

**空间复杂度**：算法所需**辅助空间**随 n 的增长量级（算法本身占用为常量）。

- 变量定义增加开销：`int a[n]` 为 O(n)，`int a[n][n]` 为 O(n²)
- 递归调用：辅助空间随递归深度增长
- **原地工作**：所需辅助空间为常量，S(n)=O(1)
